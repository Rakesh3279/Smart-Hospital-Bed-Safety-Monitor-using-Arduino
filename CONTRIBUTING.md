# Contributing

Thanks for your interest in the Smart Hospital Bed Safety Monitor.

## Before opening a pull request

- Keep the Arduino baseline buildable.
- Explain the hardware and software change.
- Include board and sensor breakout details for hardware-related changes.
- Record tests performed and actual outcomes; do not mark unrun tests as passing.
- Keep RTOS experiments isolated from the working baseline until validated.
- Update the README or relevant docs when behavior, wiring, configuration or the serial protocol changes.
- Never include passwords, access tokens, personal data, local machine paths or private serial captures containing sensitive information.

## Suggested workflow

1. Create a focused branch.
2. Make one logical change.
3. Build/test on the stated hardware.
4. Update documentation.
5. Open a pull request with test evidence and known limitations.
